## ✨ Features

- 🪑 Automated exam seating allocation
- 👨‍🏫 Faculty duty allocation
- 👨‍🎓 Student management
- 🏫 Exam hall and room management
- 📊 Exam schedules and reports
- 📄 PDF report generation
- 📥 Excel student/faculty import
- 🔐 Role-based authentication
- 📱 Responsive web interface

## 🛠️ Tech Stack

**Frontend**
- React.js
- Tailwind CSS

**Backend**
- Node.js
- Express.js

**Database**
- MySQL / MariaDB

**Authentication**
- JWT
- bcrypt
